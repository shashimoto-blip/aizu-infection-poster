# 会津感染症ポスター作成

福島県感染症情報ページで公開されている最新の週報PDFから、会津地域の「インフルエンザ」「新型コロナウイルス感染症」の定点当たり報告数を取得し、A4縦の待合室向けポスターを生成するWebアプリです。

## 使い方

1. 画面の「最新情報からポスターを作成」を押します。
2. 最新週・前週の数値と増減を確認します。
3. 「PNGで保存」からA4比率・1588 × 2246pxの画像を保存します。

数値・週・日付はSVG上にブラウザが描画します。画像生成AIによる文字描画は使用していません。

## ローカルで起動

Node.js 22.13以降が必要です。

```bash
npm install
npm run dev
```

表示されたローカルURLをブラウザで開いてください。

本番相当の確認:

```bash
npm run build
npm start
```

## 毎週の更新ロジック

ボタンを押すたびに以下を実行するため、週ごとの手作業更新は不要です。

1. 福島県感染症情報ページのHTMLを取得
2. 「20xx年」の見出しと「第xx週」のPDFリンクを組み合わせ、公開済みの最大週を選択
3. PDFの先頭ページから年・週・対象期間を抽出
4. 先頭6ページ内で「インフルエンザ」「新型コロナ」「報告数」を含む表ページを検索
5. 表ヘッダの週番号を読み、地域順の「会津」行から最新週・前週を抽出
6. 差を小数第2位まで計算し、増加は「↑」、減少は「↓」、同値は「→ 横ばい」で表示

抽出は固定座標だけに依存せず、病名キーワード、表ヘッダ、地域ラベル、行順、週番号の一致を段階的に検証します。PDFのレイアウトが大きく変わり、検証を通らない場合は誤った数値を表示せず、失敗した段階と原因を画面に表示します。

## 主なファイル

- `app/page.tsx` — 操作画面、A4 SVGポスター、PNG保存
- `app/api/latest/route.ts` — 最新値取得APIとエラー応答
- `lib/fukushima.ts` — 最新PDF特定、PDF解析、会津行抽出、整合性検証
- `public/aiki-logo.png` — ユーザー提供の会喜地域薬局グループロゴ

## データ元

- 福島県「感染症発生動向調査報告」
- https://www.pref.fukushima.lg.jp/sec/21910a/kansenshojoho.html

県ページやPDFの構成が変更された場合は、`lib/fukushima.ts` のリンク判定・表判定を更新してください。
